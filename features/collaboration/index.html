实时协作

不同设备，落笔在同一页。

用链接或二维码进入同一份白板，看见远端光标、选中范围和连续笔迹。在不同设备上，共同推进一份可以继续编辑的笔记。

从分享一张二维码开始。

现场协作不需要先加好友。房间链接、二维码与房间码，都是进入白板的入口。

  1. 创建房间

    打开要一起编辑的笔记，从协作菜单创建房间，按需要选择在线人数上限。

  2. 分享邀请

    展示房间二维码或复制邀请链接，只交给预期参与者。

  3. 扫码加入

    系统相机扫码后打开 Web；支持的 App 与 Web 可以在“加入房间”中扫码，也可以粘贴链接或房间码。

  4. 一起编辑

    看见伙伴的光标、选中范围和实时笔迹，再在同一页继续书写。实际流畅度仍与设备、网络及版本有关。

邀请链接是进入房间的凭据

链接含有解密白板所需的信息，不要公开发布或交给不受信任的接收者。

给讨论一个合适的边界。

房主可以设置人数上限、查看成员，并在确认后移出某个在线连接。

人数按连接计算
同一账号的不同浏览器或设备分别占用名额，上限包含房主；移出当前连接不等于永久封禁。
结束前保留成果
房主退出需要结束房间。加入方退出或被移出时，可按提示保存当前白板为本地笔记。
连接与保存是不同状态
光标正常不代表正文恢复或本地保存已经完成。遇到异常先保留内容，再检查网络、连接提示和两端版本。
