功能总览

每一个想法，都有继续的方式。

读一页资料，写下自己的理解，再和伙伴一起推进。FlowMuse 把这些过程放在同一个可以持续编辑的空间。

手写与 PDF

五种笔形、压感、PDF 批注、分页与模板，让记录跟得上思考。

智能整理

笔记资料库

笔记本、标签、搜索、回收站，以及由你掌握的备份方式。

了解笔记资料库

小工具，也照顾完整的流程。

不只关注写下来的那一刻，也照顾查找、展示、分享和再次打开。

语音转文字
通过系统或浏览器识别语音，把确认后的文字留在白板。适合快速补充思路，具体可用性取决于平台与权限。
形状、箭头与思维导图
把关系画出来，用文本、图片、分组、对齐和层级工具继续调整。演示时还可以使用临时激光笔。
文件导入与导出
支持 .markdraw、.excalidraw / .json 等白板文件，让内容在不同工具和协作流程之间继续使用。
属于自己的工作空间
主题、默认文档、笔形、手写笔与手势设置分别保存。桌面、平板与手机按屏幕调整界面。
