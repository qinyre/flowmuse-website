画布编辑与导出

不必一笔，就写到位。

笔迹、文本、图形、图片都可以继续调整。用选择、分组、对齐与层级工具组织表达，再通过白板文件保留和交流成果。

先落笔，再理清关系。

自由记录之后，仍然可以移动、缩放和重新组织内容。

选择与变换
框选一段笔迹或多个对象，进行移动、缩放、旋转与分组。撤销和重做帮助你尝试不同的组织方式。
图形与连接
用矩形、椭圆、菱形、直线与箭头说明关系，配合文字、图片、对齐、分布和层级顺序完成表达。
键鼠与触控
在 Web 画布中使用 Ctrl＋滚轮缩放，通过抓手、页码和“适合当前页”找回整体。
演示与讲解
使用激光笔临时指出某个步骤，讲完后把关注点还给真正的笔记。

让内容，继续被使用。

支持 .markdraw 与 .excalidraw / .json 导入导出，保持 Excalidraw 场景格式兼容。

保留一份原始文件

不同工具对扩展元素的显示可能不同；对外交流前检查目标工具中的效果。白板导出用于单份文档交流，资料库备份用于整体保存与恢复。
