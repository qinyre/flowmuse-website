鸿蒙与多端

拿起熟悉的笔，回到同一个思路。

平板适合落笔，电脑适合整理，浏览器方便一起加入。FlowMuse 围绕不同设备的输入与系统能力做适配。

这一页，聊聊鸿蒙原生能力平台与入口手写笔支持

让系统能力，接得上这一笔。

鸿蒙适配通过原生接口融入同一套笔记流程，核心内容依然能与其他设备协作。

手写笔与 Pen Kit

在支持的设备上使用笔身双击切换工具，以及系统取色等笔能力。可用行为取决于手写笔、系统版本与相关授权。

桌面服务卡片

从桌面快捷回到最近的白板，减少寻找应用和重新定位笔记的步骤。

原生 PDF 与文件

通过原生 PDFKit 和系统文件选择能力衔接阅读、批注、导入与保存。

系统语音输入

通过 Core Speech Kit 将语音转为可编辑文本，具体识别能力及联网要求由系统服务决定。

华为账号

通过系统账号授权登录，并在授权后使用相应头像与昵称；可按流程绑定邮箱，方便在其他端使用同一个账号。

应用内扫码

通过 Scan Kit 识别协作邀请，在支持的鸿蒙 App 中直接进入同一白板。

原生能力，按设备确认

系统版本、手写笔、权限和实际安装包都会影响功能表现。网页能使用核心笔记与协作功能，但不会因此自动获得原生 Pen Kit、服务卡片等系统能力。

选一块顺手的屏幕。

项目面向六个平台；安装环境和系统能力分别核对，不能把一端的表现当作全部平台的结果。

平台与使用方式
平台适合怎样使用开始之前
Web无需安装，在浏览器里记录、导入 PDF 与参与协作。直接打开网页版。摄像头、麦克风等能力取决于浏览器授权与支持。
HarmonyOS手写笔、系统取色、服务卡片、原生文件与 PDF。需要可用的鸿蒙构建与匹配的设备、系统和签名。
Android平板书写、PDF 批注、App 内扫码与协作。需要 Android 安装包；厂商手写笔事件仅在支持设备上使用。
Windows / macOS键鼠编辑、阅读、整理与参与同一白板。按对应平台构建说明准备环境，部分原生能力与移动端不同。
iOS使用同一套笔记与白板能力。需要对应 Apple 构建与签名；具体设备能力以实际安装版为准。
直接体验 Web 查看各平台构建说明
关于安装包

目前没有统一发布的 GitHub Release 安装包清单。这里提供网页版与真实构建说明，不把“目标平台”当成“已在应用商店上架”。

把切换工具，留在笔上。

在支持的鸿蒙和一加/OPPO 手写笔上，笔身双击可在书写与橡皮之间切换。

按系统设置使用
一加/OPPO 遵循当前系统的双击切换工具设置；没有通用的“所有安卓手写笔双击”兼容承诺。
起笔重压临时擦除
自由书写开始时重压并停留，可临时执行擦除，抬笔恢复。它是另一种交互，不是笔身双击。
普通工具栏仍可使用
不支持这些动作时，继续通过工具栏切换笔与橡皮。压力表现也取决于笔和设备上报的输入信息。
