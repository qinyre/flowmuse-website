# 官网多页面重构

## 目标与视觉

保留纸面背景、绿色主色、FlowMuse Sans、手写标题与现有真实截图。首页负责介绍产品和引导阅读；独立页面展开具体功能、使用步骤、平台差异及数据边界。正文以真实已交付能力为准，不展示虚构评价、用户数、性能指标或尚未提供的安装包。

参考 skills.sh 的 frontend-design、UI/UX Pro Max 与 Vercel Web Design Guidelines：采用清楚的导航层级、独立 URL、面包屑、目录锚点、可见键盘焦点、移动端触控与减少动画。UI/UX 检索的导航规则适用；其黑粉配色和字体建议不符合用户要求，继续沿用项目现有视觉。

## 实现范围

- 使用原生 HTML/CSS/JS 与已有 GSAP，不引入前端运行框架。共享布局与内容在构建时生成完整静态页面，目录路由可直接访问、刷新和分享，兼容 GitHub Pages 子路径。
- 用既有演示实录和组件截图；区分两者的说明。没有截图的能力使用文字与步骤展示，不生成虚构产品界面，不重新加入个人身份信息。
- 保留旧锚点、用户协议和独立白板演示入口。补全真实 404、站点地图、各页标题/描述、当前导航状态及下一阅读入口。
- 沿用已有动效，针对内页和减少动画调整；全部正文和导航在禁用 JavaScript 时仍可使用。

## 用户反馈后的布局与拆页

首页保持既有构图。介绍区改为固定目录与独立阅读区；移动端收起为目录菜单。进一步拆出 `/features/pdf/`、`canvas/`、`presence/`、`friends/`、`recognition/`、`layout/`、`speech/`、`backup/` 和 `preferences/`。`writing/` 聚焦自然书写，`intelligence/` 聚焦 AI 助手；不把所有功能拼在同一个长页中。

共 19 个生成页面，另保留原用户协议与历史白板演示。目录、当前页状态、面包屑和后续阅读均使用真实链接。

## Taste 设计记录

按用户要求，从 [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) 下载并安装 `design-taste-frontend`。保留静态技术栈、已有配色和字体。

项目素材清单：五种笔形、二叉树手写笔记、同主题排版画面、算法 PDF、三端协作实录、聚焦与跟随、扫码入房、鸿蒙原生适配、资料库与主题截图、本地优先的数据边界。这些是页面的内容证据，不添加虚构用户、评价或统计数字。

方向从脚本提供的三项中选择 **The split stage**，seed `20261028`。固定一侧提供阅读位置，另一侧展开实际内容。首次首屏蓝本是客房与条纹卡片，与真实素材和用户指定侧栏冲突，重抽一次为 **Menu column, sticky photograph**；按明确的目录要求，固定侧使用导航而非占半屏照片。保留品牌纸面与绿色，不套用其他配色。

设计概念：把 FlowMuse 同一份真实手写笔记及其整理结果作为介绍材料，固定目录像笔记本目录，每项功能是一张可直接打开的说明页。首页截图切换是可操作的真实内容展示；目录导航、问题深链接和大图阅读服务实际查找。

介绍页删除辅助眉题、装饰编号、密集细线和静态阴影。用背景色差区分导航和正文，使用较深的正文与更清楚的功能标题。保留首页原有手写波浪、浮动、截图切换、悬停等 GSAP 动效；内页增加分层入场、列表逐行呈现、图片轻微随滚动移动和书页切换。介绍页标题与说明不再从完全透明开始。

### 取舍

- 用户明确允许无截图功能用文字，并要求拆开路由，因此每个功能页不套“四张图片”的营销页门槛。代表页检查仅对此使用 `--allow few-pictures`，没有为了达标拼凑图片。
- 保留品牌纸色；不添加无关视频。左侧目录固定，阅读区自身左右留白相等，整页不是对称营销画报。
- 检查器将关闭的隐藏菜单计算为横向滚动行；已另行检查可见菜单和 320–1440px 布局，无实际横向溢出。
- 未引入外部摄影、生成图像或占位产品界面。截图来源见 [素材清单](website-assets.md)。
